# Source inventory (completed before staging)

Inventory scope: the source DecisionRAG experiment repository root (workspace location intentionally omitted). This inventory was written before copying any source artifacts into this release directory. File-group hashes below use a deterministic tree digest: sort relative paths; for each regular file hash its bytes with SHA-256; then hash the concatenated relative-path, byte-count, and file-hash records. This is a group digest, not a replacement for per-file hashes in the release manifest.

At the time this source inventory was first recorded, the task attachment directory contained only the packaging prompt and the experiment workspace's `paper/` tree had five local assets; no TeX source or compiled PDF was present there. The owner subsequently supplied `decisionrag_paper_and_table1_addon.zip`, which added the TeX source, bibliography, paper PDF, figures/tables, and Table I files to the release. Accordingly, the `paper/` count and digest in the original source-inventory table describe that earlier five-file workspace snapshot, not the expanded release tree. The supplied PDF and TeX files are now included. Their identity against a fresh arXiv source archive and a reproducible PDF rebuild have not been established.
