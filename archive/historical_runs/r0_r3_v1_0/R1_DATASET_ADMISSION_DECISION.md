# R1 Dataset Admission Decision

## Gate

`R1_NO_ADMISSIBLE_POPULATION`

No new model inference is admissible. CRAG is useful for the corrected exploratory audit and answer/reference proxies, but its retained release metadata does not establish a genuinely untouched, source-independent, support-annotated validation population. KILT-NQ is not locally available with an authenticated retrieved-passage contract, and admitting it would require an unapproved new indexing/retrieval campaign. Therefore R2 is not run.

The protected holdout remains unopened and no outcomes were inspected.
