# E5-A Frozen Statistical Protocol

Primary comparison: local Perplexity Decider (PPLX) versus Jina v3.5 on identical natural Top-20 slates. Primary estimand is the equal-source-group-weighted mean of within-group CSSR-U differences PPLX−Jina. Secondary query-weighted difference and CSSR-C are descriptive. Use two-sided 95% group-cluster bootstrap, 5,000 replicates, seed 731; retain query pairing within groups. Report group counts, discordant groups/queries, leave-largest-group-out and valid-case sensitivity. Invalid/missing native selector output is an intention-to-evaluate failure, with complete-valid-case sensitivity separate. No superiority or noninferiority claim is frozen. E5-F is separately locked.

The exploratory primary population is the fixed eligible E5_EXPLORATORY cohort; CAL is for protocol/index checks.
