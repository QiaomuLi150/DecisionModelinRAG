# CSSR Definitions and Test Fixtures

CSSR-U includes natural retrieval misses as zero; CSSR-C conditions on complete designated support appearing in Top-20. Support sets with zero, >5, missing/ambiguous/non-text mapping are structurally ineligible, not selector failures. Invalid Top-5 outputs are failures under intention-to-evaluate. Targeted synthetic tests cover these cases; no synthetic values are used as benchmark results.
