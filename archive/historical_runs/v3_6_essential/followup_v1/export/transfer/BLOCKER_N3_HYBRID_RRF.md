# N3 transfer blocker

The available v2.1 confirmation populations use frozen hybrid RRF first-stage slates. The v3.6 transfer specification requires the exact unchanged v2.1 pipeline and a label-free length comparison. No exact BM25-only source artifact is available, so no new transfer inference or cross-protocol equivalence claim is made. Existing v2.1 artifacts remain preserved and are not relabeled.
