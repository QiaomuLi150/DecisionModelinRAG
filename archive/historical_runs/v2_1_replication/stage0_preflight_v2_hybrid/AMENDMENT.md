# DecisionRAG v2.1 versioned input amendment

The owner approved a versioned amendment allowing the already preserved hybrid BM25-top100 + dense-top100 + RRF@60 Top-20 slates. No new retrieval was run. The original Stage-0 blocker and protocol remain unchanged. Enterprise candidate text was reconstructed from the official archive using path-qualified internal IDs and verified against the chunk-manifest text hashes. MuSiQue candidate text was resolved from the pinned passages corpus. Labels are not in the input manifest and are joined only after raw selector outputs are frozen.

This amendment changes the input contract, not models, prompts, policies, scoring, sampling, or statistical procedures.
